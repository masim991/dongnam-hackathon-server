# 해운대 12개 표시 코스 전수 점검

후속 보완: [문탠로드·동백섬·수영강 전체 경로 정리](haeundae-complete-routes.md). 아래는 교체 전 조사·검증 기록이며 현재 13개 표시 경로는 후속 문서를 기준으로 합니다.

2026-11-28 기준. 운영 지도에서 12개 항목을 실제로 하나씩 선택하고, 코스 GeoJSON의 좌표 연결·지선·중복을 검사했다. Claude는 해운대구청·부산시·비짓부산·두루누비 등 8개 HD 항목의 근거를 조사했고, Codex는 공식 갈맷길 4구간 원문과 화면·선형을 대조했다.

## 결론

**공식 GPX 전체를 확보한 것은 갈맷길 2-1·2-2·8-1·8-2의 4구간이다.** 나머지 8개는 OSM에서 고른 일부 보행로·길 모음·재구성 순환선 또는 차도 참고선이다. 공식 설명이나 길이만 발견했다고 그 자료가 현재 좌표 전체를 증명하는 것으로 처리하지 않았다.

원본 GPX(2024-10-01)와 OSM(2026-11-27)은 날짜·정확도가 다르다. 정밀한 길 좌표, 완전한 코스 범위, 현장 통행 가능성은 별도로 검증해야 한다. 30m DEM 경사도 자료의 정밀도도 길 좌표의 정밀도와 별개이며 해안·급경사에서 큰 오차가 날 수 있다.

| 갈맷길 8-1 | 10.749km | 부산시 공식 GPX 전체, 안내 10.7km | 금정구·해운대 일원, 현장 변동 별도 |
| 갈맷길 8-2 | 7.342km | 부산시 공식 GPX 전체, 안내 7.6km | 연속된 수영강 동편 코스의 기준 자료 |

| 동백섬 | 1.802km | 기존 경유점을 보존한 OSM 재구성, 일부 왕복 | 해안 데크 950m·공원 순환도로 1km와 동일 노선인지 미확정 |
| 문탠로드 | 1.456km | 일부 이름 기반 보행로와 지선 | 공식 안내 2.2km 원점회귀의 전체 GPX·경유점 좌표 필요 |
| 송정옛길 | 2.101km | 내륙 송정옛길, 구청·시 안내 약 2km | 같은 거리만으로 전체 경로 일치 판정 안 함 |
| 수영강 길 모음 | 12.530km | 3개 좌표 연결 요소, 여러 지선 포함 | 단일 완주 거리로 쓰지 않음. 연속 코스는 8-2 참고 |

거리의 정의가 다르므로 "현재 1.456/공식 2.2 = 66%만 확보" 또는 "동백섬 1.8km는 공식 950m의 두 배라 오류"라고 결론내지 않는다. 좌표 연결 통계는 0.3m 반올림 오차 허용 기준이며 보행 시설·공사 회피를 증명하지 않는다. 분리된 길을 직선으로 이어서 완성 코스로 꾸미지 않았다.

## 이번 로컬 수정

- 코스 선택 시 왼쪽 안내창/모바일 하단 패널을 제외한 지도 영역에 **전체 활성 선형**을 맞춘다. 원본 보관 레이어·신호 점을 경로 범위로 계산하지 않는다. `코스 전체 보기` 버튼으로 다시 맞출 수 있다.
- 기존 데스크톱에서 7개 코스의 좌표 일부가 안내창 아래로 가려졌다. 수정 후 12개 코스 모두 안내창에 가려진 활성 좌표와 화면 밖 활성 좌표가 0개였다.
- 코스별 `근거와 코스 범위`에서 공식 전체인지, 일부 길인지, 도로 참고선인지와 읽은 출처 링크를 표시한다. 검색 요약만 확인한 링크를 읽은 근거로 승격하지 않는다.
- 해운대해변로·달맞이길은 전체를 보행 미확인 차도 참고선(주황 점선)으로 표시하고 보행 경사·신호 계산에서 제외한다. 기존 차도 주변 횡단 집계는 그대로 남기되 성격을 설명한다.
- `송정 해안(송정옛길·동암해안길)`을 `송정옛길(OSM 보행로)`로 정정했다. 현재 6개 선형 모두 내륙 송정옛길이며 동암해안길이라는 이름을 뒷받침하지 않는다.
- 수영강은 `해운대 길 모음`으로 표시한다. 12.5km가 하나의 완주 거리처럼 보이지 않도록 3개 묶음·지선·중복을 안내한다.
- 경로 길이가 달라진 정적 코스의 횡단보도 밀도(`crossings_per_km`)를 실제 표시 길이로 다시 계산했다. D1은 변경하지 않았다.

## 근거의 사용 한계와 후속 정밀화

- [부산시 공식 2-1](https://www.busan.go.kr/galmaetgil/tour0201), [2-2](https://www.busan.go.kr/galmaetgil/tour0202), [8-1](https://www.busan.go.kr/galmaetgil/tour0801), [8-2](https://www.busan.go.kr/galmaetgil/tour0802): 구간·거리·경유점 확인. GPX 원본 날짜는 2024년이며 현장 상태의 보증이 아니다.
- [동백해안산책로](https://www.visitbusan.net/index.do?menuCd=DOM_000000202004001000&uc_seq=284&lang_cd=ko), [문탠로드](https://www.visitbusan.net/kr/index.do?menuCd=DOM_000000202004001000&uc_seq=283&lang_cd=ko): 산책 코스 설명과 안내 거리 확인. 정확한 좌표 전부를 제공하는 자료는 아니다.
- [두루누비 API](https://www.data.go.kr/data/15101974/openapi.do)는 코스·GPX 정보 조회 기능이 있으나 `serviceKey`가 필요하다. 키 발급·비공개 인증 자료 열람은 하지 않았다. 공개 GPX 링크와 보호된 API 호출을 구분한다.
- 다운로드한 두루누비 2023 GPX는 275점으로 부산시 2024 원본 1,156점보다 성기고 선형 차이가 있다. 참고 대조에 사용하며 더 정확한 정답으로 대체하지 않는다.
- 해운대구 자전거지도는 좌표·축척이 없는 JPEG 안내도다. 자전거 허용 여부와 노선 이름 참고에는 쓸 수 있으나 선형 좌표·거리의 근거로 전환하지 않는다.
- 문탠로드·동백섬·송정옛길 등의 전체 정밀화를 확정하려면 구청·관리주체의 공식 GPX/공간 선형, 또는 출처·수집일을 남긴 현장 트랙을 확보하고 OSM과 대조해야 한다. 없는 좌표를 거리 수치에 맞춰 임의로 만들어 넣지 않는다.

## 검증 상태

Node 72개·Python 9개, 타입 검사·Worker 빌드·기존 산책로 176개 파일 검사가 통과했다. UI 검사는 실제 브라우저에서 12개 코스를 하나씩 선택해 실시했다. 기존 11px 안내 글자에 대한 디자인 검사 경고 1건은 이번 변경 범위 밖으로 남겼다.

이번 변경은 로컬 작업이며 추가 커밋·푸시·운영 배포를 하지 않았다. 운영 지도는 앞선 4794e9d 배포본을 유지한다. 기존 분리 DB 관련 미완료 파일은 보존했다.
