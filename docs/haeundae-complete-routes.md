# 해운대 전체 표시 경로 보완

2026-11-28. 앞선 12개 항목 조사 이후 문탠로드·동백섬·수영강의 전체 표시 선형을 보완했다. 동백공원의 순환도로와 해안·공원 연결 순환을 구분하면서 지도 목록은 **13개**가 된다. 이는 표시 선형의 완성·연결 검증이며 현장 실측이나 모든 통행 상태를 인증한 것은 아니다.

## 최종 선형

| 항목 | 표시 거리(근사) | 출처·범위 | 연결 검사 |
|---|---:|---|---|
| 동백공원 순환도로 | 967m | 해운대 관광시설관리사업소 안내판 사진과 대조한 OSM 공원 도로 | 1개 폐합 순환, 끝점·가지·중복 간선 0 |
| 동백섬 해안·공원 연결 순환 | 1,649m | 원본 해안·공원길의 연속 경유선에서 왕복 지선을 제거한 별도 경로 | 1개 폐합 순환, 끝점·가지·중복 간선 0 |
| 문탠로드 원점회귀 | 2,551m | 들머리→바다전망대 대응지점→어울마당→해월정→들머리 | 실제 OSM 공유 노드 116쌍, 시작=끝·폐합 틈 0m |
| 수영강 동편 | 7,342m | 부산시 갈맷길 8-2의 동천교→민락교 전체 GPX(2024-10-01) | 708점 전부 보존, 연결 요소 1·끝점 2·가지 0 |

- **동백공원:** 기존 1.8km 선은 해안길과 공원길 경유에 왕복이 섞여 있었다. 안내판의 짧은 공원 순환과 해안 경유를 같은 길로 보지 않고 나눴다. OSM way 239279807에는 약 4m 진입 지선 뒤에 실제 닫힌 순환이 있다. 이 순환만 추출하여 진입 왕복을 제외했다. 별도 해안·공원 순환도 중복 없이 폐합시켰다. 어떤 거리(900·930·950m)를 맞추려고 좌표를 이동하지 않았다.
- **문탠로드:** 공식 설명·현장 안내도와 경유점 이름을 대조하여 숲길 약 1,436m, 보도 약 845m, 계단 약 101m, 광장 약 158m, 보행 미확인 서비스도로 약 12m로 구성했다. 정수 반올림 때문에 종류별 합과 총길이는 1m 정도 다를 수 있다. 해월정 곁길 왕복 약 112m가 포함되며 이는 경유 순서에 따른 실제 왕복이다. 입구·바다전망대의 정확한 이름 대응은 추정이고 공식 2.2km와 같은 노선으로 확정하지 않았다. [상세 근거와 대안](moontan-route-review.md).
- **수영강:** 기존 12.53km는 이름이 같은 여러 길을 모은 3개 묶음이었다. OSM 보행 전용 그래프를 공식 GPX 주변 40·80·120·200m에서 탐색해도 전 구간 공유 노드 경로가 없었다. 없는 보도나 접점을 만들어 넣는 대신 확보한 부산시 8-2 전체 GPX를 사용했다. 지도에 이미 있는 GM-8-2와 같은 원본임을 표시한다. 하천 전체나 양안 전체를 뜻하지 않으며 범위는 동천교→민락교 동편 구간이다.

좌표 연결 검사의 0.3m 허용은 반올림 접속 통계이며 통행 시설의 증명이 아니다. 노드 경로 생성은 경도 91,000m/도·위도 111,320m/도 근사를, GPX/감사는 위도별 경도 보정을 사용하므로 총길이 계산에 약 1m 차이가 날 수 있다. 실제 정확도는 원본 OSM·GPX 자료의 오차와 날짜에 제한된다.

## 코드와 재현

```powershell
# 갈맷길 원본 SHA가 맞아야 생성됨. 인터넷·D1 쓰기 없음.
python scripts/build-galmaetgil.py
# 문탠로드 원본 네트워크 → 순서 있는 전체 루프와 출처
python scripts/build-moontan-route.py
# 로컬 API 실행 후 읽기만 수행. D1 적재 명령 아님.
python scripts/repair-course-connectivity.py http://127.0.0.1:8788
python scripts/audit-course-coverage.py
python test/network-refinement.test.py
npm test
npm run typecheck
npm run build
npm run data:check
```

문탠로드 생성기는 `public/data/haeundae/walking-network.json`만 입력으로 읽는다. 자기 출력이 반영된 코스 파일을 다시 비교 입력으로 읽던 문제를 제거하고, 이전 숲길 비교는 고정한 원본 way ID 목록으로 계산한다. 연속 생성의 SHA-256 일치도 확인한다. 동백섬 생성기는 최대 면적의 닫힌 실제 순환을 선택하며 모든 새 선분이 명시한 원본 OSM 선분으로 설명되는지 3cm 이내 검증한다. 인위적인 대각선 연결은 생성·테스트에서 거부한다. COAST 일부 점은 기존 6자리 큐레이션 좌표를 원본 선분에 투영한 점이므로 7자리 OSM 노드 값 그대로와는 수cm 다를 수 있다. 공개 문탠 GeoJSON에는 화면에 필요한 좌표·구분·근거만 담고, 상세 조사·비교·안내판 해석은 큐레이션 원본과 문서에 보존한다.

이전 [12개 항목 조사표](haeundae-course-audit.md)·[공식 근거 조사](haeundae-course-research.md)는 교체 전 상태를 기록한 자료다. 현재 상태는 이 문서, `public/data/haeundae/course-review.json`, 정적 코스 목록과 GeoJSON을 기준으로 한다. OSM 원본 네트워크 4,278개 길은 변경하지 않는다.

## 지도와 데이터 계약

- `public/data/haeundae/courses/index.json`: HD 10개(기존 이름 집계 HD-GALMAET 포함).
- `public/data/galmaetgil/index.json`: 공식 GPX 4개. 지도가 HD-GALMAET을 숨기므로 **표시 목록은 13개**다.
- `public/data/haeundae/course-review.json`: 표시된 13개 전체의 범위·근거·연결 통계.
- 문탠로드는 추정 여부를 포함한 경유점 4개를 눌러 확인할 수 있다.
- 새 경로에는 과거 횡단보도 집계를 재사용하지 않는다. 신호는 `not_analyzed`, 수치는 `null`로 두고 0곳이라고 출력하지 않는다.
- 실제 보행 여부가 미확인인 도로는 주황 점선이며 경사 매칭에서 제외한다. 30m DEM 경사 정밀도는 길 좌표의 정밀도와 별개다.
- 기존 `/api/courses`와 D1은 9개를 유지한다. 안드로이드가 정적 새 경로를 쓰려면 위 정적 목록을 읽어야 하며 WebView 지도에는 그대로 반영된다. 새 네이티브 앱 빌드·실기기 검증은 이번 범위가 아니다.

## 검증·배포 범위

Python 회귀 검사 13개: 문탠로드의 실제 원본 노드 간선·폐합, 동백섬 두 순환의 가지·중복 제거, 대각선 가짜 연결 거부, 수영강 공식 원본 708점 보존, 기존 도로 참고선·GPX·공사 우회 회귀를 확인한다. Node는 커밋 대상 테스트 65개와 기존 로컬 분리 DB 작업의 8개를 합해 73개를 실행했다. 분리 DB 관련 미완료 파일은 이번 커밋에서 제외한다.

지도 전체 보기·근거 표시·패널 가림 개선도 함께 배포 대상이다. 운영 배포는 기존 Worker `dongnam-hackathon`의 정적 자산으로 수행하며 D1 쓰기·스키마 변경·권한 확대는 하지 않는다. 배포 후 공개 파일 해시와 API·데스크톱/모바일 실제 표시를 확인한다. 원본 기사·다운로드 파일·실행 로그는 근거와 조사 범위에 맞게 구분하며 인증 정보는 포함하지 않는다.
