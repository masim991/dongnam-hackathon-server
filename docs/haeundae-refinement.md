# 해운대 도로·보도와 갈맷길 2·8코스 정밀화

현재 상태: 2026-11-28 최종 연결 보완 및 로컬 검증 완료. D1 쓰기 없이 정적 지도 데이터로 배포한다. 로컬 미리보기는 `http://127.0.0.1:8788/map/`이다.

## 원인과 변경

기존 부울경 벡터는 20m 미만 길과 보도·횡단을 제외하고 4m 단순화를 적용했다. 길 이름이 `갈맷길`인 선을 모은 기존 `HD-GALMAET`도 공식 코스의 순서·전체 범위를 나타내지 않았다.

Claude가 해운대 행정경계(송정 포함)와 150m 여유 안의 길을 PBF에서 다시 추출했다. 길 4,278개·노드 26,603개이며 짧은 연결로를 제거하거나 단순화하지 않았다. 노드 누락·길 ID 중복은 없다. 4,247개 길이 공유 OSM 노드로 하나의 연결 요소를 이룬다. 이것은 보행 가능성을 현장 확인했다는 뜻은 아니다. 도로 2,861개는 보행 미확인으로 분리했고 제한 길 102개는 기본 지도에서 제외했다. 상세 규칙은 [네트워크 검토](haeundae-network-review.md)를 참고한다.

| 시범 코스 | 직선 대신 원본 길로 복원 | 남은 구조화 직선 |
|---|---:|---:|
| 해변 미포 연장 | 2곳 | 0곳 |
| 달맞이길 | 4곳 | 0곳 |
| 동백섬 | 수동 4곳 포함 전체 선형 재구성 | 0곳 |
| 기존 갈맷길 이름 집계 | 1곳 | 0곳 |
| 문탠로드 | 1곳 | 0곳 |
| 수영강 | 1곳 | 0곳 |

복원은 기존 끝점을 원본 선분에 0.3m 이내로 투영하고 공유 노드로 연결된 실제 길을 탐색한 결과다. 좌표가 겹치거나 30m 이내에 있다는 이유로 길을 만들지 않는다. 보행 미확인 도로를 거치는 연결은 파란 코스와 구별되는 주황 점선으로 표시한다.

달맞이길의 마지막 약 10m 틈은 실제 도로 약 313m 우회로 교체했다. 해당 끝점·3개 원본 길 ID·최대 거리로 한정한 검토 예외이며 전역 탐색 범위는 늘리지 않았다. 동백섬은 기존 68개 인접 점 쌍 모두를 공유 OSM 노드 경로로 재구성하여 수동 직선 4곳(68m)을 제거했다. 경유점을 유지하여 일부 왕복이 포함된다. 구조화 직선 9곳과 동백섬 수동 4곳이 모두 원본 경로로 대체됐으며, 도로 보행 가능 여부와 현장 통행은 별도 확인이 필요하다.

## 공식 갈맷길 원본

[부산시 전체 코스](https://www.busan.go.kr/galmaetgil/tour00)와 [2024-10-01 GPX 배포 자료](https://www.busan.go.kr/galmaetgil/notice03/1653637)를 확인했다. 원본 ZIP은 Edge에서 다운로드했고 필요한 4개 GPX만 `data/reference/galmaetgil/`에 보존했다. 출처·다운로드 URL·SHA256은 `source.json`에 기록했다. 원본이 바뀌면 빌드가 중단되므로 기준점을 다시 검토해야 한다.

| 구간 | 원본 좌표 | GPX 계산 거리 | 부산시 안내 거리 |
|---|---:|---:|---:|
| 2-1 송정해수욕장 → 민락교 | 1,156점 | 11.586km | 12km |
| 2-2 민락교 → 오륙도 진입데크 | 1,273점 | 11.349km | 11.4km |
| 8-1 상현마을 → 동천교 | 998점 | 10.749km | 10.7km |
| 8-2 동천교 → 민락교 | 708점 | 7.342km | 7.6km |

계산 거리는 부산 위도에서의 평면 근사다. 안내 거리와 GPX 계산 거리를 같은 수치로 강제하지 않는다. 원본 GPX의 모든 좌표와 트랙 구분을 보존했으며(2-1은 별도 archive 피처), 최대 연속 점 간격은 약 31m 이하이다. 과거 2022년 2-1 자료는 문탠로드에서 시작해 현재 송정 출발 안내와 다르므로 사용하지 않았다.

### 2-1 공사·우회

[2026-07-30 공식 공지](https://www.busan.go.kr/galmaetgil/notice01/1745240)는 수영만요트경기장 공사로 2026.10~2028.5(예정) 보행 통제·우회를 안내한다. [공지의 우회 지도 이미지](https://www.busan.go.kr/data/synap/20260730/files/2dc048e1-c394-45fd-80b9-fb28ff69fea5.png)도 직접 확인했다.

- 2024 GPX 중 해당 옛 트랙을 회색 점선으로 구분하고 현재 통행 안내로 사용하지 않도록 알린다.
- 안내도와 대조한 외곽 보도 약 426m와 진입 서비스도로 약 15m, 추정 접속 약 4.3m를 합친 약 445m를 주황 점선 **우회 후보**로 표시한다. 공식 좌표 기반 확정 우회선으로 표시하지 않는다.
- GPX의 987번 선분과 서비스도로 469945926의 교차점에서 시작한다. 원본 서비스도로 469945926·1126184777을 거친 뒤, 노드 7660263787에서 보도 820366480·1337948936·820366479·820339533·820339537·820339538의 공유 노드를 따라간다. 끝점은 1046번 GPX 선분과 보도의 정확한 교차점이다.
- **4.25m 접속은 OSM 공유 노드가 없다.** 공식 우회 안내도에서 연속 진입을 확인하고 그 서비스도로와 보도 사이를 데이터 정합화한 추정이다. `metadata.detour.inferredConnector`와 `hasInferredConnector`에 별도 기록하고 지도 안내에도 4.3m 추정·현장 미확인임을 표시한다. 원본 네트워크 자체에 이 연결을 추가하지 않는다.
- GPX는 2024년 기록, 보도는 2026-11-27 OSM 자료다. 원본 1,156점은 `archived_gpx` 피처로 별도 보존하고 그 피처는 보행·경사 분석에서 제외한다. 목록 거리는 2024 GPX 기준이며 변경된 선형의 길이는 `operationalLengthM`에 따로 기록한다.
- 확대 화면과 Claude 교차검토에서 발견한 잘못된 685m 내부 보도 최단 경로는 폐기했다. 빌드 시 우회선을 5m 간격으로 표본화해 통제 원본의 30m 이내 표본이 20%를 초과하면 중단한다. 원본 외곽 보도 ID도 고정하여 내부 보도가 우회로로 재선택되지 않게 한다.
- 공지의 예정 종료일이 지나도 자동으로 통제를 해제하지 않는다. 새 공식 공지와 현장 상태 확인이 필요하다.

원본 페이지는 걷기·행사 운영 활용을 안내한다. 부산시 출처·날짜·원본 해시와 파생 처리 내역을 유지한다. 개별 GPX 자료의 공공누리 유형은 확인되지 않았으며 임의 라이선스를 부여하지 않는다. OSM 출처와 ODbL 표시는 지도 및 데이터 메타데이터를 유지한다.

## 지도·안드로이드 데이터 경로

- 해운대 정밀 네트워크: `/data/haeundae/walking-network.json`
- 보완한 시범 코스 목록·GeoJSON: `/data/haeundae/courses/index.json` 및 목록의 `geojson` 경로
- 공식 4구간 목록·GeoJSON: `/data/galmaetgil/index.json` 및 목록의 `geojson` 경로

지도는 정적 목록을 우선 쓰며 기존 D1 API를 대안으로 유지한다. 공식 4구간이 있으면 기존 이름 집계 `HD-GALMAET`을 목록에서 대체해 총 12개 코스가 보인다. **기존 `/api/courses`와 D1은 그대로 9개 코스다.** 안드로이드에서 새 구간을 쓰려면 위 정적 목록도 읽어야 한다.

공식 GPX에 신호 개수가 없다는 이유로 0곳이라고 표시하지 않는다. 기존 HD 코스는 신호 집계를 유지하며, 선형을 보완한 코스에는 횡단보도 수가 보완 전 집계임을 표시한다. 도로의 보행 가능 여부가 미확인인 부분에는 보행로 경사 색을 입히지 않는다.

정적 HD 코스는 API를 읽어 만든 스냅샷이다. **향후 D1 경로를 수정하면 아래 보완 빌드도 다시 실행하고 정적 파일을 함께 갱신해야 한다.** 오래된 스냅샷을 최신 D1과 자동 동기화한다고 가정하면 안 된다.

## 재생성·검증

```powershell
# 원본 PBF 재추출이 필요한 경우만 실행. 기존 osmium 가상환경 사용.
.wrangler/osm/venv/Scripts/python.exe -m pip install -r scripts/requirements-network.txt
.wrangler/osm/venv/Scripts/python.exe scripts/extract-haeundae-network.py .wrangler/osm/south-korea-latest.osm.pbf
# 로컬 API 서버 실행 후 읽기만 수행한다. D1 적재 명령이 아니다.
python scripts/repair-course-connectivity.py http://127.0.0.1:8788
python scripts/build-galmaetgil.py
python test/network-refinement.test.py
npm test
npm run typecheck
npm run build
```

Node 테스트 69개, Python 회귀 테스트 7개와 타입 검사·빌드가 통과했다. 공식 좌표 보존, 우회 표시 접속 틈 0m·4.25m 추정 연결 명시·공사 구간 회피, 동백섬 폐합·수동 직선 제거, 별개 GPX 트랙 미연결, 공유 노드 없는 평면 교차의 미연결, 짧은 횡단로 보존, 늦게 도착한 요청, D1 장애 시 공식 목록, 미확인 도로 경사 제외, 기존 신호 집계 보존을 확인했다.

운영 읽기 검증: 코스 목록·9개 GeoJSON API 모두 HTTP 200, 해운대 주변 신호 API 82개 응답. 로컬 실브라우저에서 4,278개 길과 12개 코스를 표시했고 데스크톱 1200×800·모바일 390×844에서 가로 넘침 없이 2-1·8-2 선택을 확인했다. 근거는 `.wrangler/scaffold-review/refined-map-final-browser.json`, `gaps-closeup-browser.json`, `live-network-api-review.json`에 있다. 최종 공사 회피 검토는 `remaining-gap-research.json` 및 공식 안내도 원문을 대조했다.
